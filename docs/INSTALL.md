# 피크닉 아이폰 설치 안내 (Windows, 무료 Apple ID)

Mac 없이 Windows PC에서 무료 Apple ID로 설치하는 방법이다. 무료 Apple ID로 설치한 앱은 **7일 동안** 쓸 수 있고, 7일이 지나기 전에 다시 서명(갱신)하면 계속 쓸 수 있다. 갱신을 놓쳐도 앱만 열리지 않을 뿐, 사진과 색인은 그대로 남는다.

## 1. 준비물 (처음 한 번)

1. **iTunes** 와 **iCloud** (애플 홈페이지에서 받는 Windows용 설치 파일 버전)
   - https://www.apple.com/kr/itunes/ → "Windows용 다운로드"
   - https://support.apple.com/ko-kr/103232 (Windows용 iCloud)
   - Microsoft Store 버전은 Sideloadly 가 인식하지 못하는 경우가 있다.
2. **Sideloadly**: https://sideloadly.io 에서 Windows 버전 설치
3. 아이폰과 PC를 잇는 USB 케이블

> Apple ID 비밀번호를 Sideloadly 에 입력하게 된다. 걱정되면 설치 전용 Apple ID 를 새로 만들어 쓰면 된다 (아이폰에 로그인된 계정과 달라도 된다).

## 2. 앱 파일(.ipa) 받기

GitHub Actions 가 코드를 올릴 때마다 `Picnic.ipa` 를 만든다.

- 방법 A: https://github.com/jung-young-hwan/picnic-photo/actions → 가장 위의 초록색 실행 → 아래 **Artifacts** 의 `Picnic-ipa` 다운로드 → 압축 해제
- 방법 B (터미널): `gh run download -n Picnic-ipa -D dist` → `dist/Picnic.ipa`

## 3. 설치

1. 아이폰을 USB로 PC에 연결하고, 아이폰에서 **"이 컴퓨터를 신뢰"** 를 누른다.
2. Sideloadly 실행 → 왼쪽 위 IPA 아이콘을 눌러 `Picnic.ipa` 선택.
3. **Apple account** 칸에 Apple ID 이메일 입력 → **Start**.
4. 비밀번호와 (요청되면) 이중 인증 코드를 입력한다.
5. "Done" 이 나오면 설치 완료.

## 4. 아이폰 설정 (처음 한 번)

1. **개발자 모드 켜기**: 설정 → 개인정보 보호 및 보안 → 맨 아래 **개발자 모드** → 켬 → 재시동 → 켜기 확인.
   - 메뉴가 보이지 않으면 3단계 설치를 한 번 한 뒤 다시 확인한다.
2. **개발자 신뢰**: 설정 → 일반 → VPN 및 기기 관리 → 내 Apple ID 이메일 → **신뢰**.
3. 홈 화면의 **피크닉** 을 연다 → "사진 연결하기" → **모든 사진 허용**.

## 5. 처음 사용할 때

- 처음 분석은 사진 수에 따라 몇 시간 걸린다 (5만 장 기준 약 3~6시간).
- 충전기에 꽂고 앱을 켜 둔 채 두면 된다. 설정 탭의 "분석하는 동안 화면 켜두기" 가 기본으로 켜져 있다.
- 앱을 닫아도 다음에 열면 이어서 분석한다.
- 날짜·스크린샷·큰 동영상은 분석 전에도 바로 쓸 수 있다.

## 6. 7일마다 갱신

- Sideloadly 를 열고 같은 방법으로 다시 설치하면 7일이 새로 시작된다. 색인(분석 결과)은 그대로 유지된다.
- Sideloadly 의 **Automatic Refresh** (설치 시 Advanced options) 를 켜 두면, PC가 켜져 있고 아이폰과 같은 Wi-Fi에 있을 때 자동으로 갱신된다.
- 무료 Apple ID 는 동시에 앱 3개까지만 설치할 수 있다.

## 7. 실기기 확인 체크리스트

- [ ] 첫 화면 → 사진 연결하기 → 권한 허용
- [ ] 설정 탭에서 분석 진행률이 올라간다
- [ ] 검색: `강아지`, `바다`, `음식`, `2023년 8월`, `작년 여름`, `스크린샷`, `동영상`
- [ ] 검색: 사는 동네 이름 (지명), 간판·영수증에 있던 글자
- [ ] 정리 탭 5개 카드에 장수와 용량이 나온다
- [ ] 정리 화면에서 전체 선택 / 전체 해제 동작
- [ ] 가로로 쓸어서 여러 장 연속 선택, 화면 끝에서 자동 스크롤
- [ ] 비슷한 사진: "추천" 배지, "추천만 남기기", 그룹 전체 선택
- [ ] 길게 눌러 크게 보기, 좌우로 넘기기
- [ ] 삭제 → 시스템 확인 창 → 사진 앱 '최근 삭제된 항목'에 들어가 있는지 확인
- [ ] "제외" 한 사진이 정리 목록에서 빠지고 설정에서 제외 목록 비우기가 된다
